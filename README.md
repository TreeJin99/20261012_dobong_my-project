# 처음 쓰는 코덱스 · 내 서비스 랜딩페이지 만들기

도봉여성새로일하기센터 「AI 기반 디지털 마케터 양성과정」 실습 폴더입니다.
코딩을 몰라도 코덱스(Codex)에게 말로 시켜서 Next.js(웹사이트 뼈대 도구)로 내가 만들고 싶은 서비스의 소개 랜딩페이지를 만들고 인터넷에 올립니다. 서비스를 만들기 전에 「써 보고 싶어요」 버튼으로 써 볼 사람이 있는지 먼저 봅니다(수요 조사). 서비스 화면은 신청을 보고 나중에 만듭니다.

예: 붕어빵 파는 곳 지도 · 동네 가게 목록 · 회비 나누기 계산기 · 나에게 맞는 ○○ 테스트 · 할 일 기록장

**백엔드(서버) 없는 판입니다.** 신청은 내가 만든 구글 폼 · 네이버 폼으로 받습니다. 로그인 · 회원가입 · 결제 · 게시판 · 예약 받기는 넣지 않습니다.

준비물: 컴퓨터에 Node.js(무료, https://nodejs.org 의 LTS)가 깔려 있어야 합니다. 처음 한 번 꾸러미를 받는 데 1~3분, 저장 공간 약 350MB 가 듭니다.

보낼 문장 모음과 막혔을 때 질문과 답은 [가이드북.md](가이드북.md) 에 있습니다.

## 1. 받기

이 저장소가 통째로 내 프로젝트 폴더입니다. 규칙서 · 기술 · 사이트 뼈대가 다 들어 있어서, 받아서 열기만 하면 됩니다.

1. 이 페이지 위쪽 초록색 「Code」 버튼 → 「Download ZIP」
2. 받은 파일의 압축을 풉니다. `dobong-ai-marketer-main` 폴더가 생깁니다
3. 폴더 이름을 `my-project` 로 바꾸고 바탕화면에 둡니다

9/14 에 만든 시장조사 보고서는 옮기지 않아도 됩니다. `$start` 가 바탕화면 「내프로젝트」 폴더에서 찾아 「가져올까요?」라고 묻습니다.

맥에서는 점(.)으로 시작하는 `.agents` 폴더가 숨겨져 보이지 않을 수 있습니다. 그래도 들어 있습니다. 보려면 Finder 에서 `Command + Shift + .`

## 2. 열기

1. ChatGPT 앱을 열고 왼쪽 위에서 「Codex」
2. 입력창 바로 위 「프로젝트 선택」 → 바탕화면 → `my-project` (옆의 「이 컴퓨터」는 그대로)
3. 아래 한 줄을 보냅니다

```
$start 로 처음부터 도와주세요
```

코덱스가 인터뷰하듯 일곱 가지(왜 만드는지 · 누가 쓰는지 · 언제 불편한지 · 지금은 어떻게 하는지 · 몇 명이 버튼을 누르면 만들지 · 나중에 만들 유형 · 이름과 색)를 하나씩 묻고 되물어 생각을 정리해 줍니다. 묻고 답한 것은 `작업파일/인터뷰기록.md` 에 남고, 기획 보고서를 보여 준 뒤 「좋아요」를 받으면 랜딩페이지 · 워드 기획서(`내 서비스 기획서.docx`) · 신청 폼 문항(`작업파일/신청폼_문항.md`)을 만들고, 다음에 보낼 한 문장을 알려 줍니다.
파일을 만들기 전에 허락 창이 뜨면 「허용」을 누르세요.

## 3. 폴더 안에 무엇이 있나

```
my-project/
  AGENTS.md            규칙서. 코덱스가 이 폴더에서 항상 먼저 읽는 설명서
  사이트재료_예시.md     9/14 보고서가 없을 때 쓰는 예시 재료
  내사이트/            내 서비스 웹사이트 (Next.js 뼈대)
  .agents/skills/      기술(부를 때만 읽는 설명서) 세 개
    start/             처음 시작 · 인터뷰 → 기획 → 랜딩페이지 + 신청 폼 문항
    update/            운영하기 · 신청 폼 연결 · 공지 바꾸기 · 다시 올리기
    design/            내가 찾은 사이트 느낌으로 색 · 글꼴 · 여백 다듬기
  9월/                 9월 수업 자료 (사주 · 자기소개 프롬프트)
```

기술은 이름 앞에 `$` 를 붙여 부릅니다. 예: `$start 로 처음부터 도와주세요`

「내사이트」 폴더에는 Next.js 뼈대가 미리 들어 있습니다. 코덱스는 site.js 와 globals.css 맨 위 한 줄만 채웁니다.

```
my-project/내사이트/
  data/site.js        서비스 이름 · 한 줄 약속 · 소개 글 · 신청 폼 주소(formUrl)
  data/app-data.js    서비스 화면을 만들 때 쓰는 장소 · 항목 · 공지 한 줄
  app/globals.css     글꼴 · 색 · 크기. 맨 위 --brand 한 줄이 내 색
  app/page.jsx        첫 화면 (주소 /). 지금은 랜딩페이지 한 장
  components/         랜딩페이지 · 「써 보고 싶어요」 버튼 · 나중에 쓸 서비스 화면 다섯 가지
  next.config.mjs     서버 없이 올리는 설정 (지우지 않음)
```

만든 화면은 코덱스가 띄워 줍니다. 내 컴퓨터 주소는 http://localhost:3000 입니다.

## 신청 폼 잇기 · 올리기

1. `작업파일/신청폼_문항.md` 를 보고 구글 폼이나 네이버 폼을 직접 만듭니다. 질문 1만 필수, 연락처는 선택으로 둡니다.
2. 폼의 「보내기」 · 「공유」에서 주소를 복사해 보냅니다.

```
신청 폼 연결해 주세요: (폼 주소)
```

```
내사이트를 Vercel 에 무료로 올려 주세요.
```

고친 뒤에는 「다시 올려 주세요」를 보내야 인터넷 주소에도 보입니다. 신청은 폼의 「응답」 탭에서 봅니다. 버튼을 누른 사람 수는 10/13 에 GA4 로 셉니다.

서비스 화면은 신청을 보고 나중에 「이제 서비스 화면도 만들어 주세요」로 만듭니다.

## 4. 지켜 주세요

- 페이지에는 실명 · 전화번호 · 주소를 넣지 않습니다. 이름은 별명으로 씁니다.
- 실제 가게 이름 · 후기 · 숫자를 지어내지 않습니다. 아직 없는 서비스를 있는 것처럼 쓰지 않습니다.
- 폼에서 연락처를 받으면 「출시 알림에만 쓰고 알림 뒤 지웁니다」 안내를 붙입니다.
- 코덱스는 가끔 틀리게 말합니다. 숫자와 출처는 직접 열어 확인합니다.
- 남의 사진 · 로고는 넣지 않습니다.

## 막혔을 때

| 증상 | 해결 |
|---|---|
| 기술이 안 보여요 | 「프로젝트 선택」으로 `my-project` 를 다시 고르기. 입력창에 `$` 를 쳐서 「처음 시작」이 뜨면 정상 (폴더가 한 겹 더 들어가 있지 않은지 보기) |
| 아무 반응이 없어요 | 화면 아래 허락 창이 떠 있는지 보고 「허용」 |
| 「한도」라고 나와요 | 잠시 기다렸다가 같은 문장을 다시 보내기 |
| 화면이 안 열려요 | 「화면 다시 띄워 주세요」를 보내고 http://localhost:3000 열기 |
| Node.js 가 없대요 | 강사에게 Node.js 설치를 부탁하기 |
| 버튼을 눌러도 폼이 안 열려요 | 「신청 폼 연결해 주세요: (폼 주소)」 › 「다시 올려 주세요」 |
