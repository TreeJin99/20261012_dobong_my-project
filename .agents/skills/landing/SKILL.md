# 랜딩페이지 만들기 (landing)

`내사이트/AGENTS.md` 의 규칙을 따릅니다. 고치는 파일은 `내사이트/data/site.js` 와 `내사이트/app/globals.css` 맨 위 `--brand` 한 줄뿐입니다.

## 0. 준비
- `작업파일/서비스기획.md` 가 없으면 「먼저 기획부터 해요. 아래 문장을 보내 주세요」와 코드 상자 `$start 로 처음부터 도와주세요` 만 주고 멈춥니다.
- 이 일은 물어보지 않고 바로 합니다. 시작할 때 「2~4분 걸려요. 허락 창이 뜨면 「허용」을 눌러 주세요」라고 한 줄 알립니다.
- 빠르게 합니다: 필요한 파일만 읽고, 만든 파일을 다시 열어 보거나 그림으로 렌더해 확인하지 않습니다. 확인은 `npm run build` 한 번입니다. 워드 · 문서 도구를 따로 쓰지 않습니다.

## 1. 채우기
1. `내사이트/data/site.js`
   - theme: 기획의 느낌 (clean · warm · bold · calm). stage 는 "landing" 그대로.
   - name · promise(한 줄 약속) · description(검색 · 카톡 미리보기용 한 문장) · maker(사용자가 말한 별명. 없으면 빈 글자 "") · ctaLabel 「써 보고 싶어요」
   - about.who(손님 한 문장) · pains(불편한 순간 2~3줄, 사용자가 쓴 낱말을 살림) · features(기능 셋: 짧은 제목 + 한 줄) · steps(나오면 이렇게 써요 3단계) · makerWhy(만드는 이유 한 줄) · ctaTitle 「나오면 가장 먼저 알려 드릴게요」 · ctaText 한 줄
   - url · gaId · verification · formUrl 은 이미 값이 있으면 그대로 둡니다.
   - 서비스 성격에 맞는 type(map · list · calc · quiz · log)도 적어 둡니다(나중 서비스 화면용).
2. `내사이트/app/globals.css` 맨 위 `--brand` 를 기획의 색 코드로.
3. 지어낸 숫자 · 후기 · 이용자 수 · 가게 이름은 넣지 않습니다.

## 2. 확인하고 띄우기
1. `내사이트` 에 node_modules 가 없으면 `npm install` (1~3분).
2. `npm run build` 로 오류가 없는지 봅니다. 오류면 site.js 안에서만 바로잡습니다.
3. `npm run dev` 로 띄우고 http://localhost:3000 을 알려 줍니다.
4. `작업파일/신청폼_문항.md` 를 씁니다. 사용자가 구글 폼 · 네이버 폼에 옮겨 적을 글입니다.
   - 제목 「(서비스 이름) 먼저 써 보기 신청」, 설명 두 줄(한 줄 약속 + 「아직 준비 중인 서비스예요. 관심을 남겨 주시면 나올 때 알려 드려요.」)
   - 질문 1 (필수 · 객관식) 「이런 서비스가 생기면 써 보실 건가요?」 꼭 써 볼래요 · 아마도요 · 잘 모르겠어요
   - 질문 2 (선택 · 체크박스) 「가장 필요한 기능은요?」 보기 = 기능 셋
   - 질문 3 (선택 · 단답) 「나오면 알림 받을 연락처」 위에 「연락처는 출시 알림에만 쓰고, 알림 뒤 지웁니다.」

## 3. 보여 주고 고르게 하기
화면이 떴다고 알린 뒤, 한 번에 하나씩 번호로 묻습니다.

(1) 「느낌이 마음에 드세요? 1 좋아요 · 2 다른 느낌도 볼래요」
- 2 면 「1 깔끔하고 밝게 · 2 따뜻하고 친근하게 · 3 힘 있고 또렷하게 · 4 차분하고 믿음직하게」 중 고르게 하고 theme 만 바꿔 다시 빌드합니다. 바뀌면 새로고침하라고 알립니다.

기획에 「레퍼런스」 칸이 있으면 (1)(2)를 묻지 않고 바로 `$design` 순서로 그 레퍼런스를 입힌 뒤 「참고한 사이트 느낌으로 다듬었어요」라고 알립니다.

(2) 「참고하고 싶은 사이트가 있나요? 1 주소나 캡처를 붙일게요 · 2 직접 둘러볼게요 · 3 비슷한 사이트를 찾아 주세요 · 4 이대로 좋아요」
- 1 이면 붙여 준 주소나 캡처로 `$design` 기술의 순서를 따릅니다.
- 2 면 `.agents/skills/design/references/galleries.md` 의 목록을 그대로 보여 주고, 주소나 캡처를 받으면 `$design` 순서를 따릅니다.
- 3 이면 웹에서 이 서비스의 주제 · 느낌과 비슷한 실제 사이트 세 곳을 찾아, 실제로 열리는 주소와 무엇이 비슷한지 한 줄씩 번호로 보여 줍니다. 「열어 보고 마음에 드는 번호를 알려 주세요」라고 하고, 고른 번호로 `$design` 순서를 따릅니다. 주소를 지어내지 않습니다.
- 4 면 4로 갑니다.
- 디자인을 입혔으면 `$design` 의 「3. 알리기」대로 「더 다듬을까요?」를 묻고, 「좋아요」가 나오면 4로 갑니다.

## 4. 다음 한 문장
