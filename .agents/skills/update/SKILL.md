# 운영하기 (update)

받은 문장에 해당하는 일 하나만 합니다. 묻지 않고 바로 하고, 주소가 이상할 때만 다시 묻습니다.

| 받은 문장 | 할 일 |
|---|---|
| 신청 폼 연결해 주세요: (주소) | `내사이트/data/site.js` 의 formUrl 에 그 주소만 넣습니다. https:// 로 시작하는 구글 폼(docs.google.com/forms · forms.gle) 또는 네이버 폼(form.naver.com) 주소가 아니면 「폼의 「보내기」 · 「공유」에서 나온 주소를 붙여 주세요」라고 묻습니다. 넣은 뒤 「다시 올려 주세요」를 안내합니다 |
| (Vercel 에) 올려 주세요 | `내사이트` 에서 `npm run build` 로 확인한 뒤 `npx vercel --prod`. 처음이면 「로그인 창이 뜨면 「Continue with Google」로 로그인해 주세요」라고 한 줄 알립니다. 받은 주소를 site.js 의 url 과 루트 AGENTS.md 「내 사이트 주소」에 적고, 휴대폰으로 열어 「써 보고 싶어요」를 눌러 보라고 합니다 |
| 다시 올려 주세요 | 위와 같이 빌드 확인 후 `npx vercel --prod` 로 같은 주소에 올립니다 |
| 공지 한 줄 바꿔 주세요: … | `내사이트/data/app-data.js` 의 notice 값만 바꿉니다. 「공지 지워 주세요」면 빈 글자로 |
| 다른 곳에 올릴 파일로 만들어 주세요 (: 새 주소) | 새 주소가 있으면 site.js 의 url 에 먼저 넣습니다. `npm run build` 로 생긴 `내사이트/out` 안의 파일을 통째로 `내사이트_올릴파일_월일.zip` (my-project 바로 아래)으로 묶고 세 줄로 안내합니다: zip 을 풀어 나온 파일을 호스팅의 맨 위 폴더에 올림 · 예: Netlify · Cloudflare Pages · 카페24 같은 웹호스팅 · 주소 뒤에 /폴더 가 붙는 곳은 화면이 깨짐 |
| 내 도메인 연결하고 싶어요: (도메인) | 도메인은 사용자가 직접 삽니다(가비아 · 카페24 등). `내사이트` 에서 `npx vercel domains add (도메인)` 을 실행하고, Vercel 이 알려 준 DNS 값을 도메인 산 곳 DNS 설정에 넣으라고 한 줄씩 안내합니다. 연결되면 site.js 의 url 을 새 도메인으로 바꾸고 다시 올립니다 |
| 워드 기획서로도 만들어 주세요 | `node .agents/skills/start/assets/make_plan_docx.js` 한 번만 실행해 `내 서비스 기획서.docx` 를 만듭니다. 만든 파일을 열거나 렌더해 확인하지 않고, 다른 문서 도구를 쓰지 않습니다 |
| 링크 꼬리표 만들어 주세요 (: 행사 이름) | 내 사이트 주소 뒤에 아래 규칙으로 붙입니다. 전부 영어 소문자 · 밑줄 · 한글 없음. 카톡 kakao/message · 인스타 instagram/social · 네이버 블로그 naver_blog/post · 유튜브 youtube/shorts. utm_campaign 은 「월일_내용」(예: 1013_profile). 채널별로 한 줄씩 보여 주고 `작업파일/꼬리표링크.md` 에도 적습니다 |

- 지어낸 내용은 넣지 않습니다. 위 표에 적힌 파일 · 칸만 고칩니다.
- 고친 뒤 `작업파일/운영기록.md` 에 「날짜 · 무엇을 · 어떻게」 한 줄을 더합니다.
- 끝나면 두 줄로 알립니다: 무엇을 바꿨는지 · 다음에 보낼 문장(대개 「다시 올려 주세요」).
