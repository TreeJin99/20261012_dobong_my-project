# GA4 잇기 (ga4)

`내사이트/AGENTS.md` 의 규칙을 따릅니다. 고치는 곳은 `내사이트/data/site.js` 의 gaId 하나뿐입니다. 사이트가 gaId 로 측정 코드를 넣고, 「써 보고 싶어요」를 누르면 `cta_click` 을 보냅니다.

## 1. 측정 ID 받기
받은 글에 `G-` 로 시작하는 글자가 있으면 바로 2로 갑니다. 없으면 아래를 그대로 보여 주고 기다립니다.

1. analytics.google.com 에 내 구글 계정으로 들어가 「측정 시작」
2. 계정 이름(내 이름) · 속성 이름(서비스 이름) · 시간대 대한민국 · 통화 원. 비즈니스 정보와 목표는 아무거나 골라도 돼요
3. 플랫폼 「웹」 → 웹사이트 URL 에 내 사이트 주소(루트 `AGENTS.md` 「내 사이트 주소」) · 스트림 이름은 서비스 이름
4. 나온 측정 ID(G- 로 시작)를 복사해 보내 주세요

```
GA4 연결해 주세요: (측정 ID)
```

## 2. 넣고 올리기
1. 받은 글에서 `G-` 로 시작하는 측정 ID 하나만 뽑아 gaId 에 넣습니다. 측정 코드(`<script …>`) 전체를 받아도 ID 만 씁니다. 코드를 페이지에 직접 붙이지 않습니다.
2. `내사이트` 에서 `npm run build` 로 확인한 뒤 `npx vercel --prod --yes` 로 같은 주소에 다시 올립니다. 주소가 아직 없으면 「먼저 Vercel 에 올려 주세요」라고 하고 멈춥니다.
3. `작업파일/운영기록.md` 에 「날짜 · GA4 연결 · 측정 ID」 한 줄을 더합니다.

## 3. 확인 안내 (그대로 보여 줌)
1. 휴대폰으로 내 주소를 열고 GA4 「보고서 › 실시간」을 봐요. 「지난 30분 동안의 사용자」가 1 이 되면 연결된 거예요.
2. 휴대폰에서 「써 보고 싶어요」를 눌러요. 실시간 「이벤트 수」 칸에 `cta_click` 이 떠요.
3. 관리(왼쪽 아래 톱니) › 데이터 표시 › 이벤트 › 「최근 활동」 탭에서 `cta_click` 옆 별표(☆)를 눌러요. 이제 신청 버튼이 성과로 세어져요. 목록에 아직 없으면 최대 하루 뒤에 떠요. 내일 다시 별표만 누르면 돼요.
- 0 이면: 1분 뒤 새로고침 · 광고 차단 앱 끄기 · 측정 ID 가 내 GA4 것인지 확인.

## GA4 화면 뭐가 있어요?
이 표만 보여 줍니다.

| 메뉴 | 무엇을 보나 | 숫자 칸 (단위) |
|---|---|---|
| 홈 | 한눈 요약 | 사용자(명) · 새 사용자 수(명) · 평균 참여 시간 |
| 보고서 › 실시간 | 지난 30분 | 사용자(명) · 이벤트 이름별 이벤트 수(회) |
| 보고서 › 획득 › 트래픽 획득 | 어디서 왔나 | 세션(회) · 참여율(%) · 주요 이벤트(회) |
| 보고서 › 참여 › 이벤트 | 무엇을 했나 | 이벤트 수(회) · 총 사용자(명) |
| 보고서 › 참여 › 페이지 및 화면 | 어느 페이지를 봤나 | 조회수(회) |
| 관리 › 데이터 표시 › 이벤트 (별표) | 성과로 셀 행동 | cta_click |
| 보고서 › 참여 › 참여도 개요 | 하루 · 7일 · 30일 활성 사용자 (DAU · WAU · MAU) | 명 |

끝에 두 줄: 「실시간은 바로, 다른 보고서는 하루~이틀 뒤에 채워져요.」 · 「보고서 메뉴에 참여 · 사용자 유지가 없으면 보고서 › 라이브러리에서 「수명 주기」 컬렉션을 게시해요.」
