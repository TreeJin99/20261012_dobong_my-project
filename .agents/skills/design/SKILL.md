# 내 사이트 다듬기 (design)

뼈대(짜임 · 글 · 기능)는 그대로 두고 옷만 갈아입힙니다. 남의 사이트는 느낌만 빌리고 글 · 사진 · 로고 · 코드는 가져오지 않습니다.

## 1. 레퍼런스 받기
- 주소 · 캡처 · 후보 번호가 이미 있으면 바로 2로 갑니다.
- 없으면 묻습니다. 「1 주소나 캡처를 붙일게요 · 2 직접 둘러볼게요 · 3 비슷한 사이트를 찾아 주세요」
  - 2 면 `references/galleries.md` 의 목록을 그대로 보여 주고 기다립니다.
  - 3 이면 웹에서 이 서비스의 주제 · 느낌과 비슷한 실제 사이트 세 곳을 찾아, 실제로 열리는 주소와 무엇이 비슷한지 한 줄씩 번호로 보여 주고 고르게 합니다. 주소를 지어내지 않습니다.
- 이어서 한 번만 묻습니다. 「그 사이트에서 무엇이 좋아요? 1 색 · 2 글꼴 · 3 넉넉한 여백 · 4 버튼 · 모서리 (여러 개 골라도 돼요)」

## 2. 살피고 입히기
1. 주소면 그 페이지를, 캡처면 그림을 보고 고른 항목만 뽑습니다(바탕색 · 포인트 색 · 글꼴 종류 · 제목 크기 · 여백 · 모서리). 페이지를 못 읽으면 「화면 캡처를 붙여 주세요」라고 합니다.
2. 바꾸기 전에 `내사이트/app/globals.css` 맨 위 `:root { … }` 묶음과 `내사이트/data/site.js` 의 theme 값을 `작업파일/디자인기록.md` 에 「바꾸기 전 · 날짜」로 복사합니다.
3. 먼저 가장 가까운 theme(clean · warm · bold · calm)을 고르고, 그 위에 globals.css 의 값만 바꿉니다. 새 글꼴이 필요하면 globals.css 맨 첫 줄에 구글 폰트 `@import` 한 줄과 제목용 `font-family` 한 줄을 더합니다. jsx · className 은 고치지 않습니다.
4. `내사이트` 에서 `npm run build` 로 확인하고, 본문 · 버튼 글자가 바탕과 잘 구분되는지 봅니다. 흐리면 색을 조금 진하게 고칩니다.

## 3. 알리기
- 바꾼 것을 표 한 장(칸 · 전 · 후)으로 보여 주고 `작업파일/디자인기록.md` 에 「바꾼 뒤 · 날짜」를 더합니다.
- 끝에 두 줄: 마음에 안 들면 「디자인 되돌려 주세요」 · 다음 문장. 다음 문장은 `내사이트/data/site.js` 의 formUrl 이 비어 있으면 「신청 폼 연결해 주세요: (폼 주소)」, url 이 비어 있으면 「내사이트를 Vercel 에 무료로 올려 주세요.」, 둘 다 있으면 「다시 올려 주세요」.

## 되돌리기
「디자인 되돌려 주세요」를 받으면 디자인기록.md 의 마지막 「바꾸기 전」으로 `:root` 와 theme 을 되돌리고, 더했던 `@import` · `font-family` 줄을 지운 뒤 빌드합니다.
